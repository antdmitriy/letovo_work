# Инструкции для агента

## Хранение проектов

- Все проекты и рабочие документы сохраняй на компьютере пользователя в текущей рабочей папке. На этом компьютере это `C:\Users\dmitriy.antonnikov\Documents\ChatGPT\@daemon3D`.
- Для каждого проекта создавай отдельную подпапку. На другом компьютере используй соответствующую локальную рабочую папку.

## Синхронизация между компьютерами

- Репозиторий рабочих файлов: https://github.com/antdmitriy/letovo_work.git.
- В начале каждой работы проверяй локальное состояние Git и удалённый репозиторий, получай новые изменения и подтягивай новые файлы до начала редактирования.
- Если локального клона нет, настрой его в рабочей папке, сохранив уже существующие файлы. Не перезаписывай локальные документы при настройке.
- Для обычного обновления используй `git fetch` и `git pull --ff-only`. При локальных изменениях или расхождении истории сначала сохрани работу и разреши ситуацию без потери файлов.
- После создания или изменения рабочих файлов сохраняй их локально, добавляй относящиеся к задаче файлы в Git, создавай коммит с понятным описанием и отправляй его в общую рабочую ветку репозитория (по умолчанию `main`). Пользователь заранее разрешил эти коммиты и push для синхронизации документов.
- Перед push проверь новые удалённые изменения. Не используй force push и не уничтожай чужие или локальные изменения.
- Синхронизируй сам `AGENTS.md`, чтобы правила были доступны на обоих компьютерах.
- Не добавляй пароли, токены, секреты и временные технические файлы в репозиторий.
- Если синхронизация не удалась, сохрани локальные результаты и прямо сообщи пользователю, что именно не было загружено или отправлено. Не утверждай, что оба компьютера синхронизированы, без проверки.
